# 需要您決定的事:系統要怎麼分辨每一位廚師

> 2026-09-15 · 智慧廚房監測系統

---

## 一句話說明問題

**大家戴口罩、穿一樣的制服,攝影機很難分辨誰是誰。**
系統要知道「是哪一位廚師做了這個動作」,就必須先分得出人。

---

## 目前做到什麼程度

我們用公開的多人測試影片(辦公室場景,斜角攝影機,每個人衣服不同)測試:

- 在**同一台攝影機**裡,系統能把同一個人一直認成同一個人的程度,**不到一半**(目前最好的設定約 47%)
- 驗收標準是 **90%**,而且「把兩個人認成同一個人」的錯誤要 **1% 以下**
- 目前離標準很遠

主要卡在**人和人靠近、互相遮擋的時候**:系統只看得到「這裡有一個人的框」,分不出框裡是誰,容易把兩個人對調,或把同一個人當成新的人。

⚠ 測試影片是辦公室、每個人衣服不同;您的廚房**大家穿一樣的制服**,只會更難。

---

## 兩個方案

### 方案 A:在廚師身上加「可辨識標記」

**做法**:每位廚師的帽子頂端或肩膀,貼上**不同顏色的色塊或編號標籤**。系統每一次看到人,就直接讀標記知道是誰。

| 項目 | 說明 |
|---|---|
| 預期效果 | 把「認人」變成「認標記」,分辨錯誤**有機會接近 0%**(前提是攝影機看得到標記) |
| 員工要配合 | 上班時配戴指定的帽子或貼紙,不能互換 |
| 成本 | 帽子或標籤本身便宜;需要確認攝影機解析度夠不夠讀到標記 |
| 個資 | **不使用人臉**,不涉及生物特徵個資 |
| 風險 | 標記被遮住(轉身、低頭)時暫時讀不到;需要測試標記要做多大 |

### 方案 B:不加標記,靠「位置、時間、行走路線」

**做法**:系統記住每個人在什麼時間站在哪裡、往哪個方向走,靠這些延續身份。

| 項目 | 說明 |
|---|---|
| 預期效果 | 先前電腦模擬(假設攝影機從正上方拍)估計,把兩個人認錯的比例**約 5~8%**,**高於 1% 的標準**;您的攝影機是斜角,可能更差 |
| 員工要配合 | 不需要 |
| 需要的現場工作 | 每台攝影機要做「地面校正」:在地上標 4 個以上的點,量出它們在平面圖上的位置 |
| 必須接受的後果 | 事件報表只能標註「信心度」;需要追責時要**人工回看影片**確認 |

---

## 我們的建議

**方案 A(加標記)**。在「口罩 + 同款制服 + 斜角攝影機」的條件下,這是目前唯一能讓系統**每次都直接分辨是誰**的方法;方案 B 在模擬中就已經達不到標準。

---

## 需要您回答的問題

1. **能不能要求廚師配戴標記?**(帽子、肩章、背後編號等)可以接受哪一種形式?
2. **同一時間廚房裡通常有幾位廚師?**尖峰時段呢?
3. **攝影機**:型號或解析度、安裝高度、大約拍到多遠的範圍?
4. **能不能做地面校正?**(需要在地上標點、量平面圖座標,每台攝影機約半小時)
5. 如果選方案 B,**「事件只標信心度、需要時人工回看」是否可以接受?**
