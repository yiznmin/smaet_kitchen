## 一、今天的結論

1. **M5 綁不對,和 M4 追得好不好無關**:M5 決定「綁給誰」的分數不含任何「這是誰」的資訊,只看「重疊鏡頭上掛了幾個身份」
2. **M4 修了 3 輪都沒有有效解決**:最好的單鏡頭 IDF1 是 **0.4710**(驗收標準 0.90),照工作規則停下
3. **設計本身有問題**:身份只在 track 出生時決定一次,之後不再檢查,整套系統被 M4 的連續性綁死
4. **現場條件讓外觀辨識不可行**:廚師**戴口罩、穿同款制服**,鏡頭**斜角**(使用者確認)
5. **待業主決定**:是否在廚師身上加**可辨識標記**(帽頂/肩膀色塊或編號)—— 目前唯一能「每次偵測就認出是誰」的訊號

### 3. 調查:為什麼 M4 做好了 M5 仍綁不對

- 成功綁定 2,286 次**全部**來自同一個常數公式 `3.806 − ln k`(k = 重疊鏡頭上掛著的身份數),**k ≤ 8 就必定綁**
- 走轉場路徑的分數在數學上**不可能**過門檻(最高 1.484 < 1.609)
- 59 人第一次出現,27 人立刻被綁到別人身上
- 文件:`docs/M5_綁定規則實測_20260915.md`

### 4. 使用者決定先修 M4 → 誤偵與遮擋的診斷

| 發現 | 數字 |
|---|---|
| 誤偵過半是**玻璃上的人影倒影**(camera_5、6) | 「幾乎不碰到人」的誤偵 80% 在這兩台 |
| 使用者決定排除 camera_5、6,改用 5 台 | 誤偵率 34.0% → 24.4%(M4 本身沒有變好,只是縮小範圍) |
| 剩下的誤偵大多是**同一個人被多開一條 track** | 框在真人身上的誤偵 85.8% 是重複 |
| 混人發生在**兩人交錯遮擋**時 | 第一次換人時兩人框互相重疊 94.6% |
| 框幾何、等幾秒再決定、擋下重疊出生 | 都分不開「重複」與「真的新人」 |
| 外觀:同鏡頭沒被擋時分得開,框重疊時分不開 | d′ 2.39 vs 換人時刻選對 62.3% |

- 另外更正:拓撲的 7 對重疊鏡頭與實際空間不一致,實際同一個房間的只有 camera_2 + 3
- 文件:`docs/M4_誤偵組成診斷_20260915.md` §1–§14、`docs/CHIRLA_鏡頭佈局實測_20260903.md` §7
