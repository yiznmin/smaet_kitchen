# M5 端到端首次串接(2026-08-25)

> `scripts/m5_track_video.py` —— **M4 與 M5 第一次真的串起來**。
> 在此之前兩者只有各自的合成驗證,全 repo 沒有任何檔案同時 import
> `m4_track` 與 `m5_reid`(見 `docs/M5_v3_重設計與可行性驗證_20260824.md` §1)。

## 為什麼現在做

模擬連續兩輪(第六輪地面校正)卡在自己的 bug 裡,邊際效益下降。
真實影片提供一個**獨立的現實檢查點** —— 而且歷史證明有效:第五輪那個
「M5 收不到每幀位置」的缺口,就是被真實情境逼出來的。

## 管線

```
多支影片 → M3 偵測(只留「人」)→ 每鏡頭一個 KitchenTracker
        → ① 心跳:把「誰此刻在畫面上」全部餵進 M5(必須在事件之前)
        → ② 事件:new_track / reacquired / lost_track / removed → M5
        → chef_events.jsonl(含 score 與 n_candidates,供事後稽核)
```

## 結果(EPFL 三視角,COCO 預訓偵測器,70 幀 × 3 鏡頭)

| t(s) | 鏡頭 | track | chef | 綁定 | 分數 | 候選 |
|---|---|---|---|---|---|---|
| 0.00 | cam1 | 1 | 1 | 新 | — | 0 |
| 0.00 | cam3 | 1 | **1** | **是** | 3.81 | 1 |
| 0.00 | cam2 | 1 | **2** | 新 | — | 0 |
| 1.07 | cam1 | 2 | **1** | **是** | 3.81 | 1 |

**管線通了,而且行為完全符合 config:**

1. **cam3 正確綁回 cam1 建立的 chef 1**(重疊路徑,3.81 nats)
   —— 這是跨鏡頭身份第一次在真實影片上成立。
2. **cam2 開了新身份**,因為 `configs/camera_topology.yaml` 的 `overlapping`
   只列了 `[cam1, cam3]`。EPFL 三個視角拍的是同一個人,所以 chef 2 是一次碎裂
   —— **成因不是演算法,是 config 沒填**。這實地印證了前五輪的結論:
   **拓撲 config 決定一切**。
3. **t=1.07 的 cam1 track 2**:M4 斷軌後重開的新 track,透過與 cam3 的重疊
   **正確接回 chef 1** —— 跨鏡頭幾何救回了同鏡頭的斷軌。

單鏡頭 20 幀的對照:1 個人 → 1 個 chef_id 全程維持,無碎裂。

## 途中踩到的整合陷阱(端到端才會出現)

**「人」的 class_id 依權重而異,而且接錯不會報錯。**

| 權重 | 人的 class_id |
|---|---|
| COCO 預訓 RF-DETR | **1**(COCO category_id) |
| 我們微調的 11 類 | **0**(`src/m3/classes.py` 的 `CAT2CLS` 是 category_id − 1) |

第一次跑時用了 0,結果**一個人都沒偵測到,而且完全沒有錯誤訊息**,
只是安靜地輸出 0 筆綁定。已改成依有無 `--weights` 自動判斷,
並在摘要印出「偵測到人 N 次」,N=0 時明確提示。

這類「靜默錯配」正是模擬看不到、只有端到端才會暴露的問題。

## 誠實限制

- **EPFL 是單人資料集** → 無法測「多人同時在場時分不分得出誰是誰」,
  而那正是目前唯一剩下的失效模式(誤併)。
- 用的是 **COCO 預訓偵測器**,不是我們微調的 11 類模型
  (微調權重在專案根目錄,加 `--weights` 即可)。
- 只跑了 70 幀(CPU 約 644 ms/幀 × 3 鏡頭)。長時間穩定性未驗。
- **沒有 homography** → `world_xy=None`,重疊路徑退回常數證據
  (`overlap_llr=5.0`,已知是過度自信,見第六輪 R8)。
- EPFL 為 CC-BY-NC,**僅供驗證不出貨**。

## 用法

```bash
# 單鏡頭(先確認管線通)
python scripts/m5_track_video.py --videos data/epfl/Boutput0.mp4 --cameras cam1 \
    --stride 10 --max-frames 20

# 多鏡頭(EPFL 視角同步,以幀號對齊)
python scripts/m5_track_video.py \
    --videos data/epfl/Boutput0.mp4 data/epfl/Aoutput0.mp4 \
    --cameras cam1 cam3 --stride 4 --max-frames 70

# 用微調權重(人的 class_id 會自動切成 0)
python scripts/m5_track_video.py --weights "checkpoint_best_regular (4).pth" ...
```
