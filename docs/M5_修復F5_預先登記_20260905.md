## 1. 診斷:轉場路徑不是「證據弱」,是**數學上不可能綁定**

2026-09-04 實測:轉場路徑 `p_break = 54.42%` —— 拒掉近半的**真**配對。
本輪先量清楚原因,再動手。

轉場路徑的分數是:

```
transit_llr = log p(Δt | 同一人) − log λ_bg     (+ 外觀 ±0.03)
```

CHIRLA 拓撲的 `λ_bg = 0.0482`(每 20.7 秒一位新人)。
⚠ 這個值是**誠實估**的 —— `chirla_build_topology.py:84` 數的是
「該身份在該序列的**首次**出現」,不是「有新 track 冒出來」,沒有循環論證。

所以要過門檻 1.609,需要 **pdf(Δt) > 0.24 /秒**。實際擬合出來的分布:

| 連結 | 峰值 Δt | 最佳 LLR | 能過門檻的 Δt 範圍 |
|---|---|---|---|
| camera_6→camera_7 | 0.65s | **+2.68** | 0.20 ~ 1.30s |
| camera_2→camera_6 | 3.30s | **+1.41** | **完全過不了**(差 0.20) |
| camera_7→camera_5 | 10.75s | **+0.70** | **完全過不了** |
| `unknown_path`(涵蓋 21 對裡的絕大多數) | — | **−1.33** | **完全過不了** |

> **3 條連結有 2 條、加上 unknown_path,在任何 Δt 都過不了門檻。**
> 外觀只能加 ±0.03 nats,補不上這個缺口。

⚠ 這也解釋了轉場路徑為何**同時**有高碎裂(54.42%)與高誤併(44.72%):
能綁上的幾乎只有同鏡頭重關聯(`SameCameraTransit`)與 camera_6→camera_7
那個 1.1 秒的窄窗,其餘的真配對全被拒。

## 2. 補的證據:「你是從通往這裡的那個門出去的嗎」

人不是從房間任意位置消失、再從任意位置出現的 —— 他們**走門**。
同一條連結 A→B 的真實轉場,離開 A 的腳點會聚在「通往 B 的門」。
可從推導集的真值學出來。

```
LLR = [log N(退場點; μ_exit, Σ_exit) + log A_from]
    + [log N(入場點; μ_enter, Σ_enter) + log A_to]
```

### ⚠ 只有退場項能區分候選

入場項只取決於這條新 track 自己的位置,**對所有候選都一樣** ——
它影響「綁不綁」,不影響「綁哪一個」。
**真正在挑人的是退場項。** 這一點必須在報告裡寫清楚,否則會高估它的鑑別力。

### ⚠ 用混合模型,不用純高斯

純高斯在 600px 外會給 **−90 nats**(σ=45px 時),只能靠 clip 硬夾 ——
那讓這條證據變成**硬性閘門**,一個繞路回來的**真**同一人會被直接否決。

```
p(退場點) = (1−ε)·N(μ, Σ) + ε·U(A)
```

下界自然是 **log(ε) ≈ −2.30**(ε = 0.10),不需要靠 clip。
這與 `transit_model="loiter"` 的 `p_loiter` 是同一個慣用法。

### ⚠ 不得與 `direction` 同時開啟

`DirectionLR` 是同一份資訊(從哪個方向離開)的離散粗糙版(n_zones=3,且一直關閉)。
同時開會把同一份證據算兩次。**`CameraTopology` 在建構時直接丟 `ValueError`**,
不靜默雙計。

### σ 的處理與 F4 **不同**,理由要講清楚

F4 的單應性用**留出樣本**估 σ(擬合過的點殘差偏小)。
F5 的高斯 μ/Σ 是**閉式估計**不是最佳化,沒有那個問題;真正的風險是 n 小時 Σ 不準。
所以改用**預測共變異數** `Σ_pred = Σ·(1 + 1/n)`:
n 大時趨近 Σ,n 小時自動放寬(= 證據自動變弱),方向是安全的。

讓正證據的上限降低。⚠ 若 ε 提到 0.3 仍無效,結論是
「這條連結的出入口不具鑑別力」,應該**不建立該連結**而不是繼續調。

## 6. 已知限制(報告要照抄,放在結論之前)

1. **只有退場項能區分候選**,入場項對所有候選相同。不得把兩項的合計
   當成「鑑別力」報告。
2. **出入口位置是用真值身份學的。** 部署時對應業主手冊的**安裝走動校正**,
   且要誠實說:安裝校正拿到的轉場樣本數會遠少於推導集三個序列。
3. **`p_offdoor = 0.10` 是工程判斷不是實驗結果。** 它直接決定證據的下界 log(ε)。
4. **`tp_min = 15` 決定哪些連結會被建立。** 換門檻結果會變,原始診斷存在
   `crossview_fit.json` 可重算。
5. **CHIRLA 是辦公室不是廚房。** 廚房的動線與門的數量都不同。
6. **`λ_bg = 0.0482` 這個值本身沒有被檢驗過**是否適合當「新人到達率」——
   它決定了整條轉場路徑的門檻高度。本輪不動它,但它是下一個該查的參數。
