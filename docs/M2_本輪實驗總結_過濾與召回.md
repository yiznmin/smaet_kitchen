# M2 分支 B — 本輪實驗總結(過濾降量 + 召回不誤殺 + 水漬凍結)

> 本輪聚焦「**證明幾何過濾有效且安全**」:砍掉大量雜訊候選的同時,不誤殺真目標;並修正水漬久置被吸收的問題。
> 版本 v1(2026-06-15)。資料來源:EPFL `Boutput0.mp4`(1280×720,全程有人、無真目標 = 最壞情況)。

---

## 1. 本輪做了什麼

| 項目 | 內容 | 程式 |
|---|---|---|
| **降量實驗** | 量「有過濾 vs 沒過濾」送進分類器的候選數 | [exp_filter_funnel.py](../scripts/exp_filter_funnel.py) |
| **召回實驗** | 把真目標貼進有人有雜訊真片,量過濾後是否還活著(測誤殺) | [exp_recall.py](../scripts/exp_recall.py) |
| **水漬凍結** | 確認後凍結該區、不讓慢速基準吸收 → 水漬持續被標記 | [static_line.py](../src/m2_motion/static_line.py) `freeze_confirmed` |

## 2. 量測方法(重要)

### 2.1 降量:兩條線用不同手法

**動態線(老鼠)— 一次跑,反推漏斗。**
偵測器每幀回報各層砍掉幾個(`n_excluded` 空間、`n_dense_excluded` 密度、`n_pending` 時序未確認、`n_crops` 最終)。因過濾是逐層相減,可反推原始數量:

```
原始候選 R = n_crops + n_pending + n_dense_excluded + n_excluded
空間後 = R − n_excluded;密度後 = 空間後 − n_dense_excluded;最終 = n_crops
```

全片加總即得漏斗。**「未過濾」不是另跑一遍,而是把各層砍掉的加回去**(每層誠實回報 → 反推)。

**靜態線(水漬)— 真的跑兩遍 A/B。**
靜態過濾(地板 ROI、動作排除、長寬比)做在遮罩裡無法逐顆反推,故跑兩遍:
- 過濾全關:`floor_zone=None`、長寬比門檻超大、動作排除最小、密度不砍、`persistence=1`
- 過濾全開:完整 config
各自統計全片送出的 crop 總數相比。

### 2.2 召回:把「已知位置」的真目標貼進真片

**不是隨機**,而是**受控合成 + 已知座標**(才能精確判斷有沒有被誤殺):
- **老鼠**:14×10 暗色小橢圓,沿**決定性 ping-pong 路徑**在地板來回(每幀移 5px + 輕微上下擺動),確保不出畫面。兩個固定擺位:開闊地面(x0=380)、貼近人(x0=600)。
- **水漬**:扁平橢圓 + 反光點,貼在地板固定位置靜止不動。
- 因為位置是我貼的、已知 → 每幀直接比對「目標中心是否落在保留的 blob 內」= 命中。
- **召回 = 命中幀數 / 目標在場幀數**。召回高 = 沒被過濾誤殺。

## 3. 數據

### 3.1 降量(送進分類器的候選 crop 數,全片加總)

**動態線(老鼠)逐階段漏斗:**

| 階段 | 累計候選數 | 相對原始 | ~每幀 |
|---|---|---|---|
| 原始(未過濾) | 143,996 | 100% | ~62 |
| 空間排除後 | 80,019 | 55.6% | ~35 |
| 密度排除後 | 5,285 | 3.7% | ~2.3 |
| 時序後(最終送分類器) | 2,116 | 1.5% | ~0.9 |

**總降量 −98.5%**;最大功臣是**密度排除**(80,019→5,285,砍密集的人碎塊)。

**靜態線(水漬)A/B:**

| 設定 | 累計候選數 | ~每幀 |
|---|---|---|
| 過濾全關 | 58,540 | ~25 |
| 過濾全開 | 8,813 | ~3.8 |

**降量 −84.9%**。

### 3.2 召回(過濾會不會誤殺真目標)

| 目標 | 情境 | 召回 | 解讀 |
|---|---|---|---|
| 老鼠 | 開闊地面(正常) | **82.5%** | ✅ 不誤殺 |
| 老鼠 | 緊貼人(最壞) | 46.9% | 已知取捨;真實老鼠少緊貼人 |
| 水漬 | 凍結前 | 3.1% | 慢速基準吸收所致(非過濾誤殺) |
| 水漬 | **凍結後** | **70.3%** | 持續標記;缺口為人經過時暫遮 |

---

## 4. 結論

- **過濾有效**:砍掉 **85~98.5%** 的雜訊候選 → 大幅降低分類器負載與誤報基數。
- **過濾安全(不誤殺)**:正常情境真目標召回維持高檔(老鼠 82.5%、水漬 70.3%)。
- **水漬凍結**:解決久置被吸收問題,讓水漬標記到清掉為止。
- **M2 的職責是定位+推送**(高召回),最終 老鼠/水漬/拒絕 判斷由多類別分類器負責。

---

## 5. 已知限制

- 召回測的是**合成目標**(暗橢圓),驗證的是「小/移動/孤立目標能否通過幾何過濾」,**不等於分類器能認得真老鼠**(那需要真實老鼠影像,屬分類器階段)。
- 老鼠路徑為簡化 ping-pong,非真實竄動;可日後加**多隨機擺位/速度**做更廣的壓力測試。
- 數據在「全程有人、無真目標」的單一最壞情境片;不同場域/光線需重測。
- 「貼近人」召回偏低為設計取捨(寧可邊緣漏,也不被人海淹沒)。
