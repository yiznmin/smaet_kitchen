## 結論:效果很小,基本打平(test 略偏 B,但在雜訊內)

- **兩份資料不一致**:**test** 上 B 略勝(整體 F1 0.835 vs 0.807;刀具/容器 precision 較高),但 **val** 上兩臂打平(A 整體甚至微高)。→ 差異很可能落在**雜訊內**,**不能斷言「先 Roboflow」真的有用**。
- 唯一比較一致的小訊號:test 上 B 的 precision 略高(刀具/容器誤報少一點);val 沒複製這個。
- **誠實說**:這份實驗**沒能證明分階段明顯有幫助**——最多是「持平、可能有一點點 precision 好處」。原本的預期(頭重置 + COCO 已涵蓋刀/容器 → 幫助有限)**大致成立**。
- ⚠ Arm B 還多練了 Roboflow 40 epoch(算力較多)卻沒換到穩定優勢 → 更說明幫助有限。test 僅 90 圖,±2~3 F1 分本就在雜訊範圍。

### 這份實驗真正證明的事(比 A/B 之爭重要)
**把資料標多才是關鍵躍進**:兩臂 val mAP@50 都到 **~0.95**、test F1 ~0.81~0.835;而 bootstrap(90 張)val mAP@50 只有 **0.85**、鍋子/砧板 AP 只有 0.09~0.22。540 張後鍋子/砧板 AP 衝到 **0.73~0.77**。→ **主力是標多、標好資料,不是分階段這種小 trick。**

### 採用建議
- **A、B 都可以**,差異不明顯。想省事就用 **Arm A(EPFL-only,更單純)**;Roboflow 前置成本低,想留著也不虧,但別期待它帶來明顯提升。
- 下一步別再糾結分階段,**專注:①真實資料標多標好 ②每類信心門檻調校**。

> **2026-08-20 更新**:Arm C(混合訓練)跑完後,建議收斂為 **直接用 Arm A(純自標資料),Roboflow 訓練上不必納入**。
> 三種接法(不用 / 分階段 / 混訓)結果一樣,納入只是多一份標註品質不可控的相依。
