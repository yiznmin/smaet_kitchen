## 1. 一鍵總結:微調前 vs 微調後(test 集,IoU≥0.5)

這是本筆記本自訂評估給的**同一把尺**(base 與微調後用同一標準,可直接對比):

| 變體 | 微調前 定位Recall | 微調後 定位Recall | 微調後 **分類正確Recall** |
|---|---|---|---|
| **nano** | 0.310 | 0.833 | **0.794** |
| **medium** | 0.294 | 0.841 | **0.817** |

**怎麼讀**:
- **微調前 ~0.30**:COCO 原始模型只框到約三成物件,而且**類別是 COCO 的**(不認得我們 11 類)→ 印證「現成模型不夠用」。
- **微調後 定位 ~0.84**:框到率提升到 2.7 倍。
- **微調後 分類正確 ~0.80**:框到**且類別也對**——這才是真正可用指標。**微調有效,方向明確。**

## 1.1 微調後 各類別 Precision / Recall / F1(test 集,thr=0.3、IoU≥0.5)

正式的操作點指標(依信心配對同類 GT 算 TP/FP/FN;`n` = 該類 test 物件數)。
**整體:nano P0.824 / R0.817 / F1 0.821;medium P0.825 / R0.825 / F1 0.825 → 幾乎完全一樣。**

| 鍋鏟 | 10 | 0.778 / 0.70 / 0.737 | 0.80 / 0.80 / **0.80** | medium |
| 鍋子 | 5 | 0.60 / **0.60** / 0.60 | 0.667 / 0.40 / 0.50 | nano(但兩者都弱) |

| 容器 | 23 | 0.727 / 0.696 / 0.711 | 0.826 / 0.826 / **0.826** | **medium** |

**讀法**:

- **砧板 precision 只有 0.571**(兩者一樣):framework 會把別的東西誤判成砧板 → 也是資料量問題。
- 提醒:`n` 只有 5~23,單一物件對錯就會讓數字跳,**別過度解讀單類差異**。

### 指標各是什麼意思(速查)
| 指標 | 白話 | 食安重要性 |
|---|---|---|
| **IoU** | 預測框和真答案框的重疊比例(0~1);≥0.5 才算「框對」 | 判定門檻 |
| **Recall** | 真的有的物件,抓到幾成(漏抓率的反面) | ⭐ 最重要,寧多抓不漏 |
| **Precision** | 模型說「有」的裡面,對幾成(誤報率的反面) | 次要,太低會吵 |
| **F1** | Precision 與 Recall 的調和平均(綜合分) | 綜合看 |
| **AP** | 各信心門檻掃過去的 PR 曲線面積(單類綜合力) | 類別整體實力 |
| **mAP@50** | 所有類別 AP 在 IoU=0.5 的平均 | 模型總分 |
| **mAP@50:95** | IoU 從 0.5 到 0.95 平均(更嚴格,要求框很準) | 定位精細度 |

## 3. 判讀(誠實版):這次 medium 略勝,但**不能定案**

**這一次 run**:medium 在食安關鍵類別上明顯較穩——
- **刀具 Recall**:nano 0.75 → medium **1.00**
- **砧板 Recall**:nano 0.50 → medium **0.83**
- **食材 AP**:nano 0.305 → medium 0.370
- 整體 mAP@50 也是 medium 高(0.854 vs 0.820)、分類正確 Recall 高(0.817 vs 0.794)。

**但關鍵發現是「跑兩次結果會跳」**:

| | 上一次 run | 這一次 run |
|---|---|---|
| nano best mAP@50:95 | 0.458 | 0.436 |
| medium best mAP@50:95 | 0.485 | 0.457 |
| 刀具 Recall(nano / medium) | 1.00 / 0.875 | 0.75 / 1.00 |

→ 在**15 張 val / 126 個 test 物件**的規模下,單類別 Recall 只要差 1~2 個物件就會翻盤。**兩次 run 誰勝誰負都在雜訊內。**

> 補充:上面「medium 略勝」是看 **val 的 AP/Recall**;但看 **test 集正式的 Precision/Recall/F1(§1.1)整體幾乎完全一樣**(F1 0.821 vs 0.825),逐類互有小勝、食安關鍵類甚至微幅偏 nano。兩份獨立資料都指向同一件事:**這規模分不出高下。**

### 結論
- **微調有效**:兩變體都把定位從 ~0.30 拉到 ~0.84、test 整體 F1 ~0.82 → 流程完全驗證。
- **變體仍不鎖定**:val 上 medium 略優、test 上幾乎打平(甚至微偏 nano),變異度太大,**不足以定案**。
- **真正定案 = 拿到真實資料(幾百張、多樣)再跑同一份一鍵筆記本**,那時數字才穩、才有決策力。
- 部署面若最終分數接近,**nano 更輕**(30.7M vs 33.6M、T4 更省),對本機 3050 友善,是加分項。
