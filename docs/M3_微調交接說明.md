| 順序 | 類別 | 說明 / 框什麼 |

## 2. 準備資料(你的主要工作)

流程:**影片 → 抽幀成圖 → 每張圖用 bbox 框出 11 類 → 切 train/valid/test → 打包 zip**

### 2.1 抽幀(把影片變成一張張圖)
最簡單用 ffmpeg,例如每 2 秒抽一張:
```bash
ffmpeg -i 你的影片.mp4 -vf "fps=1/2" frames/frame_%05d.jpg
```
建議:
- **量**:至少幾百張起跳,越多越好。
- **多樣性**:涵蓋不同時段、光線、鏡位、有人/沒人、不同料理動作——比「張數多但都很像」更重要。
- 優先挑**有動作、桌面上有物件**的畫面,空景少放。

### 2.2 標註(框 bbox)

**標註器要用你自己的圖片重新產生一份**(圖片是嵌在 HTML 裡的,不能直接沿用我方那份)。
只需要 Python + `opencv-python`、`numpy`,在專案目錄執行:

```bash
pip install opencv-python numpy
python scripts/make_bbox_labeler_html.py \
   --img_dir 你的frames資料夾 \
   --out results/m2/labeler_real.html \
   --classes 人,刀具,砧板,食材,鍋鏟,鍋子,手,容器,抹布,夾子,手套
```
> ⚠ `--classes` 的**內容與順序照抄上面這串**,一個字都不要改(這決定了類別對應)。

產生後**雙擊 `labeler_real.html`** 用瀏覽器打開(全程本機、不上傳):
- 拉滑鼠畫框框住物件 → 下拉選單或**數字鍵**選類別 → `←/→` 換圖 → `d` 刪最後一框。
- 標完按 **⬇ 匯出 coco.json**。
- 沒出現的物件就跳過,不用硬框。

**標註品質要求**:
- 框要**貼緊**物件邊緣(太鬆會拉低 AP)。
- **同一張圖裡所有出現的目標物件都要框**(漏框會被模型學成「這裡沒東西」)。
- 被部分遮住的物件,框**可見的部分**即可。

### 2.3 切分資料集
用 `scripts/split_coco.py`(把標好的 COCO 切成 train/valid/test):
```bash
python scripts/split_coco.py --labeled 你的標註.json --img_dir 圖片資料夾 --out_base dataset_out
```
產出 `dataset_out/{train,valid,test}/`,每個資料夾內含圖片 + `_annotations.coco.json`。把 `dataset_out` 壓成 **`dataset.zip`**。

### 3.3 微調 nano
```python
from rfdetr import RFDETRNano
model = RFDETRNano()
model.train(
    dataset_dir='/content/m3ds',
    epochs=60,
    batch_size=4,
    grad_accum_steps=4,
    lr=1e-4,
    resolution=704,          # 高解析度,幫助偵測小物件;必須是 32 的倍數
    output_dir='/content/out_nano',
)
```
> OOM(記憶體不足)就把 `batch_size` 降到 2、`resolution` 降到 640。
> 過程會每個 epoch 印出 val mAP,**把最後那張表截圖交回**。

### 3.5 快速驗證(看有沒有真的學會)
```python
from rfdetr import RFDETRNano   # 驗 medium 就換 RFDETRMedium、out_nano 換 out_medium
model = RFDETRNano(pretrain_weights='/content/out_nano/checkpoint_best_regular.pth', num_classes=11)

import glob, os
from PIL import Image
NAMES={0:'人',1:'刀具',2:'砧板',3:'食材',4:'鍋鏟',5:'鍋子',6:'手',7:'容器',8:'抹布',9:'夾子',10:'手套'}
for p in sorted(glob.glob('/content/m3ds/test/*.jpg'))[:8]:
    det = model.predict(Image.open(p).convert('RGB'), threshold=0.3)
    print(os.path.basename(p), '->', [NAMES.get(int(c), int(c)) for c in det.class_id])
```
> ⚠ **不要呼叫 `model.optimize_for_inference()`** —— 會讓每張圖偵測結果變成一模一樣(模型被凍成常數)。直接 `predict` 就好。
> ⚠ 顯示類別要用 `det.class_id` + 上面的 `NAMES`,**不要**用內建的英文名(那是 COCO 預設,不是我們的類別)。

## 4. 怎麼判斷微調成功

| 看什麼 | 好的樣子 |
|---|---|
| val 的 **mAP@50** | 越高越好(bootstrap 90 張就到 ~0.85;真實資料多應更高更穩)。 |
| **各類別 Recall**(食安最重要) | **刀具、砧板、食材、手**的 Recall 越高越好——代表「不漏抓」,食安寧可多抓不可漏。 |
| test 圖預測 | 開始正確抓到刀具/砧板/食材等自訂類別(不是只有 person)。 |

**交回時附上這些數字**,我方會據此決定最終用 nano 還是 medium。

## 5. 常見雷(照做可避開)

| 症狀 | 原因 | 修法 |
|---|---|---|
| `No module named 'pytorch_lightning'` | 只裝了推理版 | 裝 `"rfdetr[train,loggers]"` |
| `resolution not divisible by 32` | 解析度不是 32 倍數 | 用 704 或 640 |
| 每張圖偵測結果一模一樣 | 呼叫了 `optimize_for_inference()` | 別呼叫,直接 predict |
| 類別顯示成英文 person/bowl | 用了 COCO 預設名 | 用 `det.class_id` + 自訂 NAMES |
| 免費 GPU 用到額度上限 | Colab 免費有上限 | 等幾小時~隔天冷卻,或改用 Kaggle Notebooks(獨立額度) |
| `files.upload()` 一直沒反應 | 在等你選檔 | 點「選擇檔案」選 dataset.zip |
