## 1. 與先前的差異

先前的違規判定(`docs/M6_違規判定_單人_預先登記_20261021.md`)用 24 個「沒洗手」事件片段,觸發時間用標註起點或片段內偵測。
片段只有十幾秒,看不到「丟完垃圾之後」較長時間的行為,也量不到「假觸發造成的假違規」。
本輪改在**整場連續影片**上跑完整流程:觸發 → 髒手 → 洗手 / 碰觸 → 判定,真值由 EPFL 官方逐秒動作標註自動推出。

## 2. 階段 1:YH2040 / 2023_09_12_09_50_41(780 秒,9 台快取已有)

限制:YH2040 是 M3 訓練場次(偵測偏樂觀);只有 3 次丟垃圾;**沒有吃東西**(EPFL 無 Taste、團隊標註無吃東西)→ 吃東西留到階段 2。

### 2.1 真值(由 `actions_annotations.xlsx` 自動推出)

- 觸發:每個 Put Trash(Start、End)。
- 髒手期間:從觸發 End 起,依時間順序看之後的標註動作(上限 120 秒或下一個觸發,先到者):
  - 先出現 Wash Hand → **合格**
  - 先出現「接觸動詞 + 食材 / 器具名詞」→ **違規**,違規時刻 = 該動作 Start
    - 接觸動詞 = `src/m6_assoc/gt.py` 的 CONTACT_VERBS(Wash Hand、Dry Hand 除外)
    - 名詞經 NOUN_TO_CLASS 對到 violation_rules.yaml 的 touch_classes(食材、刀具、砧板、鍋鏟、鍋子、容器);抹布不算
  - 都沒有 → **未解除**
- 事先檢視:3 次丟垃圾(52.2、68.1、286.1 秒)依此規則都是**違規**(之後分別先碰番茄、刀、碗)。

### 2.2 系統流程(全部用 integrated/ 模組與凍結設定,不再調)

1. 垃圾桶觸發,兩組:
   - base:Aoutput1 手 + output0 身體(事件測試第 3 輪凍結)
   - mv:多鏡頭 kofn strict k 3、thr 0.2、T 0.5(`docs/M6_多鏡頭觸發_預先登記_20261027.md` §8.4)
2. 擦手排除(新規則,兩組都測開 / 關):觸發起點在「偵測到的洗手片段結束後 15 秒內」→ 視為擦手,不算觸發。
   洗手片段 = 洗手序列間隔 < 1 秒合併、累計 ≥ 1 秒。
3. 每個觸發:從觸發結束 + grace 1 秒起跑 HandHygieneFSM(洗手 = close_hand、wash_s 1;碰觸 = touch_series 角色分工融合),
   上限 120 秒或下一個觸發。
4. 輸出:每個觸發一筆(觸發時間、判定、判定時刻、碰到的類別)。

### 2.3 指標

- 觸發對應:系統觸發區間與真值 [Start − 2, End + 2] 重疊 = 對到。
- **判定正確率**:對到真值的觸發中,判定與真值相同的比例(未解除另列)。
- **漏判**:真值違規但沒有觸發或判合格。
- **假違規**:沒對到真值的觸發被判成違規的次數 / 每小時。← 階段 1 的主指標
- 違規時刻誤差:對到且雙方都判違規時,|系統判定時刻 − 真值違規時刻|。

### 2.4 假說

| 編號 | 假說 | 成立條件 |
|---|---|---|
| SQ-H1 | 流程能把真的違規抓出來 | 3 個真值違規中系統判違規 ≥ 2(base 或 mv 任一) |
| SQ-H2 | 擦手排除能降低假違規 | 開啟後假違規數減少 ≥ 50%,且真值違規抓到數不減 |
| SQ-H3 | 整場假違規可接受 | 最佳組假違規 ≤ 2 次(≈ 每小時 9 次) |

預期:SQ-H1 成立(3 個都是丟完馬上碰食材);假觸發多在擦手時 → SQ-H2 可能成立;SQ-H3 不確定。

### 8.1 階段 1 結果(YH2040,2026-10-27)

指令:`python scripts/eval_violation_sequence.py --session yh2040`(9 秒);輸出 `results/m6/sequence/yh2040_*.csv`。
真值:3 次丟垃圾全是違規(之後先碰番茄 53.3、刀 68.5、碗 287.8 秒)。

| 觸發 | 擦手排除 | 觸發數 | 真值違規抓到 | 假違規 | 每小時 | 未解除 | 違規時刻誤差中位 |
|---|---|---|---|---|---|---|---|
| base | 關 | 15 | 3 / 3 | 7 | 32 | 5 | 1.4 秒 |
| base | 開 | 9 | 2 / 3 | 6 | 28 | 1 | 1.5 秒 |
| mv(4 台 k 3) | 關 | 8 | 3 / 3 | **3** | 14 | 2 | 1.1 秒 |
| mv | 開 | 3 | 2 / 3 | 1 | 5 | 0 | 1.3 秒 |

逐筆(mv、擦手排除關):
- 真違規 3 個都判違規,判定時刻比真值晚約 1 秒(grace 1 秒)。
- 假違規 3 個:15.6 秒(洗手後在垃圾桶上的毛巾擦手 → 28.5 秒碰砧板)、605.9 秒(走過垃圾桶 → 616 秒碰鍋鏟)、644.7 秒(走過碰毛巾 → 646 秒碰鍋鏟)。
- 768、774 秒(洗手後擦手)判未解除:之後沒碰到食材就結束。

擦手排除的副作用:51.9 秒的真丟垃圾被排除 —— 它前面 41–50 秒在水槽洗東西(不是洗手)被偵測成洗手片段,丟垃圾落在 15 秒內。

另見:碰觸序列整場 502 / 780 秒成立(64%),所以只要有觸發、之後沒洗手,幾乎一定判違規 → **假觸發會直接變成假違規**,觸發的準確度決定一切。

### 8.3 檢討與下一步

1. 流程可用:先後順序判定在真違規上全對,時刻誤差約 1 秒。
2. 問題在觸發:剩下的假違規全來自「擦手」與「走過垃圾桶」。
3. 擦手排除用「洗手後 15 秒」太粗:水槽洗東西也被當洗手,會誤刪真丟垃圾。
   候選改法:觸發期間手與抹布有關聯(M3 抹布框 + 手)→ 視為擦手;或觸發要求身體朝向 / 停留(走過時停留短)。
4. 只有 3 個正例、M3 訓練場次 → 數字只供方向參考,要在階段 2 的 8 場驗證。
