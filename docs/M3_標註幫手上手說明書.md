# 物件標註 — 幫手上手說明書

> 給協助標註的夥伴。你的工作是幫這個「智慧廚房」專案**擴充與校對物件框標註**。
> 全程用**瀏覽器工具**,不用寫程式、不用安裝軟體。雙擊一個 HTML 檔就能開始。

---

## 0. 你的任務是什麼、為什麼重要

我們在訓練一個**能自動偵測廚房畫面中物件**的 AI(刀具、砧板、食材、手…)。
AI 要學得好,需要**大量「人工框好答案」的圖**。目前只有 90 張,**太少 → AI 表現不穩**。

**你的工作**:對一批廚房畫面,**用滑鼠把每個物件框起來、選它是哪一類**。
你標得越多、越準,AI 就越聰明。你有食安概念,正好能判斷「這是食材還是容器」「有沒有戴手套」這類細節。

> 註:這批是公開研究影片(EPFL),**只用來練習與驗證流程**;請勿外流影片或圖片。

---

## 1. 開始前(專案負責人給你的東西)

你會收到一個檔案:**`labeler.html`**(裡面已經內建所有要標的圖)。
- 直接**雙擊用瀏覽器(Chrome/Edge)打開**即可。
- 全程在你自己電腦上跑,不會上傳,關掉前記得**匯出存檔**(見第 4 節)。

> 給專案負責人的前置(做一次):
> ```bash
> # 1) 從影片多抽一些有動作的幀(例:每視角 40 張)
> python scripts/extract_multiview_frames.py --per 40
> # 2) 產生標註器(內建這些圖 + 11 類)
> python scripts/make_bbox_labeler_html.py \
>    --img_dir data/m3_finetune/mv_images \
>    --out results/m2/labeler.html \
>    --classes 人,刀具,砧板,食材,鍋鏟,鍋子,手,容器,抹布,夾子,手套
> ```
> 把產生的 `results/m2/labeler.html` 交給幫手即可。

## 2. 操作方式(30 秒學會)

| 動作 | 怎麼做 |
|---|---|
| **畫框** | 在物件上**按住滑鼠拖一個方框**框住它 |
| **選類別** | 拉框**前**先用**下拉選單**或**數字鍵**選好是哪一類 |
| **換下一張 / 上一張** | 鍵盤 **→ / ←** |
| **刪掉這張最後一個框** | 按 **d** |
| **存檔** | 按 **⬇ 匯出 coco.json** |

畫錯了就按 `d` 刪掉重畫。**沒有出現的物件就不用管**。

---

## 3. 要標的 11 類 — 框什麼 / 不框什麼

**原則**:框到物件的**可見範圍**,框線**貼緊**邊緣。有食安疑慮的細節(戴不戴手套、食材有沒有落地)正是重點。

| 類別 | 框什麼 | 不框 / 注意 |
|---|---|---|
| **人** | 整個人(身體) | — |
| **刀具** | 菜刀、水果刀等手持刀 | 鍋鏟不算刀具 |
| **砧板** | 切菜板 | — |
| **食材** | **所有食物/食材都算這一類**(肉、菜、蛋…不細分) | 裝在碗裡的食材:食材框食材、碗框容器(兩個框) |
| **鍋鏟** | 鏟子、湯勺、料理長匙 | — |
| **鍋子** | 炒鍋、湯鍋、平底鍋 | — |
| **手** | 露出的手/手掌 | **有戴手套時 → 框「手套」不框「手」** |
| **容器** | 碗、盆、保鮮盒、料理盆 | 鍋子不算容器 |
| **抹布** | 抹布、擦手巾 | — |
| **夾子** | 料理夾 | — |
| **手套** | 戴在手上的手套 | 沒戴在手上、單獨放的手套也框手套 |

### 常見邊界案例(你會遇到)
- **物件被手/其他東西擋住一半** → 只框**看得到的部分**。
- **兩個東西疊在一起**(如砧板上有食材)→ **各框各的**(砧板一個框、食材一個框)。
- **同一類有很多個**(如三根紅蘿蔔)→ 分得開就**各框一個**;糊成一團分不開就框一整團。
- **太模糊看不出是什麼** → 不確定就**跳過不框**(寧可不標,不要標錯)。
- **手拿著刀** → 手(或手套)一個框、刀具一個框。

## 4. 交回方式

1. 每標一段就按 **⬇ 匯出 coco.json**(瀏覽器會下載一個 `coco.json`)。
2. 建議**每天/每批**匯出一次,檔名加日期(如 `coco_0724.json`),避免當掉全部重來。
3. 把 `coco.json` 交回給專案負責人。

> ⚠ 關掉瀏覽器分頁前**一定要先匯出**,否則當天標的會不見。

---

## 5. 品質守則(這幾點做到,標註就合格)

1. **框要貼緊** — 不要框太大留一堆空白,也不要切到物件。
2. **該框的都框** — 畫面裡出現的目標物件盡量不漏(漏標會讓 AI 學錯)。
3. **類別選對** — 尤其**手 vs 手套**、**食材 vs 容器**別搞混。
4. **不確定就跳過** — 模糊、看不清的,寧可不標。
5. **一致性** — 同樣的東西每次都用同一類、同樣的框法。

---

## 6. 進度與節奏

- **不設每日張數目標**——以**標得準、標得一致**為優先,不用趕量。
- 一次標一段、記得匯出(見第 4 節),累了就休息,避免疲勞標錯。
- 有拿不準的案例,**截圖問專案負責人**,一起補進本說明書的「邊界案例」。

---

## 7. 校對任務(進階,若有餘力)

除了標新圖,也可以**檢查已標好的圖**有沒有:
- 框**太鬆 / 切到物件** → 調整。
- **漏標** → 補框。
- **類別標錯**(手/手套、食材/容器) → 改正。

校對能直接提升現有資料品質,和標新圖一樣有價值。
