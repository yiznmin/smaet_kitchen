## 1. 目的

新資料(自家廚房、新類別 手機 / 衛生紙)要標框。先用現有模型產生草稿框,人只做「補漏、刪錯、微調」,不從零開始畫。
本測試回答:草稿能省多少人工、哪些類別可以靠草稿、SAM 3 在 M3 沒學過的情況下能不能先頂著用。

## 2. 資料

- `D:/yizhen/m3_fintune_data/m3_finetune_r2/`(EPFL 影格,人工標 11 類)
  - valid 90 張:選門檻、選合併方式
  - test 90 張(828 框):凍結後只跑一次
- 注意:M3 權重(`integrated/weights/m3_nano_r2_armA`)用同一批的 train 訓練、門檻用 valid 掃。
  test 是同場地、同鏡頭 → M3 的數字是「已在這個廚房訓練過」的**上限**,不代表新廚房。
  SAM 3 沒看過這批資料,它的數字比較接近「新廚房、M3 還沒訓練」的情況。
- 手機、衛生紙在這批沒有人工框,只能數草稿框數量與目視抽查,不計分。

## 5. 指標

- 逐類 P / R / F1:同類、IoU ≥ 0.5、信心排序貪婪配對(沿用 `src/m3/eval.py` 的 `counts_for_class`)。
  夾子、手套在 test 沒有樣本,不計分。
- **修正量** = 漏框(FN,人要補)+ 錯框(FP,人要刪)。**修正率** = 修正量 / 人工框數。
  從零開始畫 = 修正率 1.0;修正率越低省越多。
- 輔助:配對成功但 IoU < 0.75 的框數(人可能要拉邊)。

## 6. 假說與判準(test)

| 編號 | 假說 | 成立條件 |
|---|---|---|
| PL-H1 | M3 草稿在已訓練過的場地可大幅省工 | A 修正率 ≤ 0.25 |
| PL-H2 | SAM 3 補框可提高抹布、手的 recall | C 的抹布、手 recall 各比 A 高 ≥ 0.05,且 precision ≥ 0.6 |
| PL-H3 | SAM 3 單獨(沒訓練)可當新廚房的第一版草稿 | S 修正率 ≤ 0.6(省 40% 以上) |

預期:PL-H1 成立(M3 test F1 約 0.9);PL-H2 不確定(M3 的抹布、手已經不錯);PL-H3 不確定,食材、容器的定義與 SAM 3 的概念差很多,可能拉低。

### 8.1 執行紀錄(2026-10-27)

- valid 第一次跑到選設定時報錯:M3 輸出 1 個 class_id 11 的框(多餘類別槽,信心低),`draft_A` 改為只留 0..10。模型原始框不受影響,只重跑選設定。
- valid 選出:SAM 3 門檻 人 0.8、刀具 0.7、砧板 0.8、食材 0.6、鍋鏟 0.4、鍋子 0.6、手 0.7、容器 0.8、抹布 0.8,其餘 0.5;
  合併範圍 = cloth_hand(valid 修正率 0.286,all 0.607)。`results/prelabel/frozen.json`。
- 90 張 × (M3 + SAM 3 15 個提示)約 8 分鐘(RTX A6000)。

### 8.3 錯框目視檢查(`results/prelabel/test_fp_*.jpg`,各 30 個)

- **SAM 3 抹布錯框**:幾乎全是真的抹布 / 海綿(掛在垃圾桶上的紅格毛巾、水槽邊的黃海綿、黃布),人工框沒標。
  人工標註的慣例看起來只標「使用中」或部分抹布 → 這類錯框是**標註慣例不一致**,不是 SAM 3 認錯。
- **SAM 3 容器錯框**:調味罐、油瓶。人工慣例不把瓶罐算容器 → 同樣是定義不同。
- **M3 手錯框**:混合 —— 腳(涼鞋)、毛巾、手腕 / 手臂局部(部分可能是漏標)。

| 編號 | 結果 | 判定 |
|---|---|---|
| PL-H1 | A 修正率 0.193 ≤ 0.25 | 成立 |
| PL-H2 | 抹布 A 已 R 1.00,無空間;手 C 與 A 同為 R 0.913 | 不成立 |
| PL-H3 | S 修正率 0.669 > 0.6 | 不成立(但 §8.3:相當一部分「錯框」是標註慣例不同) |

### 8.5 探索(未登記,設定依 valid 選、test 只看一次)

- 「M3 草稿,但手改用 SAM 3」:valid 修正率 0.198 → 0.155;test 0.193 → **0.145**(P 0.928、R 0.928);
  代價是手的「要拉邊」從 19 → 39(SAM 3 手框範圍與人工慣例不同)。`results/prelabel/*_explore_A_handS.json`。

### 8.6 結論與建議

1. 已訓練過的場地:M3 草稿只需修約 19% 的框(手改用 SAM 3 約 15%),等於省 80% 以上的畫框工作。
2. 新廚房 / M3 沒訓練過時:SAM 3 單獨當草稿目前要修 67%,省得不多;主要卡在「什麼算容器、什麼算抹布」的定義跟 SAM 3 不同。
   要用 SAM 3 先頂,必須**先定標註慣例**(例:所有抹布都要標?瓶罐算不算容器?),再依慣例調提示詞或過濾。
3. 新類別(手機、衛生紙)只能靠 SAM 3 提出;EPFL 本來就少,框數很少,實際效果要等自家資料抽查。
4. 建議流程:新資料第一批用 SAM 3 草稿 + 人工修 → 訓練 M3 → 之後用 M3 草稿(手用 SAM 3)。
5. 標註工具已可載入多類草稿(虛線)、右鍵刪單框、`--draft_min_score` 篩信心。
