## 3. 系統(每一類一條規則;凍結部分不再調)

共用零件(凍結,integrated/ 模組):
- 洗手:close_hand(Boutput1、Boutput2 手在洗手台 zone,wash_s 1 秒)
- 碰觸:touch_series(角色分工融合;touch_classes = 食材、刀具、砧板、鍋鏟、鍋子、容器)
- 垃圾桶污染觸發:多鏡頭 kofn_strict k 3、thr 0.2、T 0.5

| NG | 系統規則 | 可在開發集調的 |
|---|---|---|
| NG1 | 污染觸發(5 秒內合併)→ 從結束 + grace 1 秒起,**先碰到 touch 類別、之前沒洗手** → NG1(記在該觸發) | 無(垃圾桶);非垃圾桶污染源見下 |
| NG2 | 髒手期間,碰觸序列每個起點(間隔 < 1 秒合併、長度 ≥ 0.3 秒)算一次,直到洗手 | 合併間隔 {0.5, 1, 2} 秒 |
| NG3 | Qwen3-VL-8B 吃東西(事件測試定案:thr 0.3、Aoutput1 或 output0)。事件層用整個視窗;實例層用 2 秒滑動窗(步長 1 秒),p ≥ thr 的段落間隔 < 2 秒合併,每段算一次 | 實例層 thr {0.3, 0.5, 0.7} |
| NG4 | (a) 清洗:手 + touch 類別物件同時在洗手台 zone ≥ w 秒;(b) 放桌面:清洗後該類別物件出現在洗手台 zone 外、與手框 IoU = 0、與砧板 / 容器 IoA < 0.3,持續 ≥ p 秒 → 算 1 次;(c) 再使用:(b) 之後沒有清洗就碰到該類別 → 再算 1 次 | w {0.5, 1, 2}、p {1, 2} |

非垃圾桶污染源(摸手機、擦鼻子、撿地上東西、擦地板、摸洗手槽):
M3 沒有手機 / 衛生紙類別,第一輪用 Qwen3-VL-8B 在視窗內每 1 秒問一次(output0 + Aoutput1 拼圖)
「這個人是否正在摸手機、用衛生紙擦鼻子、撿地上的東西或擦地板?」,yes 段落當污染觸發。thr 在開發集選 {0.3, 0.5, 0.7}。

## 4. 指標(每一類分開)

- **事件層**:每個團隊事件 → 系統在視窗內有沒有判到該類 NG。
  R、P、F1、混淆表;正例 = 有該類 NG 的事件,反例 = 其他所有團隊事件(含別的類別,以量跨類誤判)。
  NG1、NG2 另報「依類別拆」(垃圾桶 / 沒洗手)。
- **實例層**:系統每個 NG 實例(時間點)落在某個團隊 NG 片段 [起 − 2, 訖 + 2] 內 = 對到(一對一,貪婪);
  R = 對到的團隊實例 / 團隊實例,P = 對到的系統實例 / 系統實例。
- **時刻誤差**:對到的實例,|系統時刻 − 團隊片段終點|(NG2、NG3、NG4)或起點(NG1)。
- **NG4**:事件層 + 實例層(放桌面、再使用分開)。

## 5. 假說(測試集判定)

| 編號 | 假說 | 成立條件 |
|---|---|---|
| NG-H1 | 垃圾桶 NG1(順序真值)可用 | 垃圾桶類事件 F1 ≥ 0.75 |
| NG-H2 | NG2 逐次計數可用 | 實例層 R ≥ 0.6 且 P ≥ 0.5 |
| NG-H3 | NG3 沿用 VLM 可用 | 事件層 R ≥ 0.6 且 P ≥ 0.8 |
| NG-H4 | 非垃圾桶污染源 NG1(VLM)有用 | 沒洗手類事件 R ≥ 0.5(探索性,測試集只有 2 個,開發集一併報) |
| NG-H5 | NG4 規則可行 | 事件層 R ≥ 0.5(探索性) |

預期:NG-H1 可能成立(垃圾桶觸發與碰觸都已驗證);NG-H2 不確定(碰觸序列整場 64% 成立,分次計數可能偏多);
NG-H3 R 約 0.6 邊緣;NG-H4、NG-H5 很可能不成立(第一次做)。
