# M2 分支 B — 合成老鼠 demo 影片(資料與說明)

> 把**合成老鼠**貼進真 EPFL 廚房做成可播放影片,疊上分支 B(動態線)偵測框。
> 用途:視覺展示「老鼠出現 → 被抓到」端到端 + 幾何過濾的動態壓力測試(竄動、走停)。
> ⚠ 老鼠為程式合成(非真老鼠影像),**不可用於訓練分類器辨識真老鼠**。
> 產生器:[scripts/make_mouse_video.py](../scripts/make_mouse_video.py);版本 v1(2026-06-15)。

---

## 1. 怎麼做的

- 來源:EPFL `Boutput0.mp4`(1280×720@30fps),**逐幀在記憶體裡貼老鼠**,原始影片不動。
- 老鼠:程式畫的(身體橢圓+頭+尾+眼),灰褐色;**決定性竄動路徑**(走 ~12 幀每幀 9px → 停 ~8 幀,沿地板 x∈[360,1120] 來回 + 上下緩擺)。
- 進場:第 120 幀(讓 MOG2 背景先建立);全片取前 900 幀(~30 秒)。
- 疊框:跑 `SmallTargetDetector`,**命中老鼠的框=綠色**、其餘候選=細灰;左上標 DETECTED/...。
- 輸出:`results/m2/mouse_demo.mp4`(~13.3 MB,gitignore 不入庫)。

---

## 2. 資料

| 指標 | 值 |
|---|---|
| 影片長度 / 幀數 | ~30 秒 / 900 幀 |
| 老鼠進場 | 第 120 幀 |
| 老鼠在場且過 persistence 的幀 | 777 |
| 被偵測到(命中)幀 | 365 |
| **整片偵測率** | **47.0%** |

### 為什麼是 47%(不是召回實驗的 82.5%)

本片老鼠路徑 x∈[360,1120],**橫跨整個地板、會經過人的位置(中右 ~700–850)**:

| 老鼠所在 | 結果 | 對應召回實驗 |
|---|---|---|
| 開闊地面(x 偏左,遠離人) | 命中(綠框、DETECTED) | 開闊地面 82.5% |
| 走到人旁邊 | 被空間/密度排除誤殺、漏掉 | 貼近人 46.9% |

整片是「開闊 + 貼近人」混合,落在兩者之間 ≈ 47%,與召回實驗([recall_experiment.md](../results/m2/recall_experiment.md))一致。

## 3. 觀察:系統「人眼難辨也抓得到」

合成老鼠顏色 `(88,92,104)` 與灰地板接近 → **人眼幾乎看不到(保護色)**,但偵測器照樣抓到。
原因:**MOG2 靠「會動」偵測,不靠顏色對比**。只要移動,偽裝再好也會被背景相減揪出。

> 代價:對外展示時老鼠不夠顯眼(可改深色高對比重產展示版,偵測邏輯不變)。

抽幀(放大可見老鼠):`results/m2/mouse_demo_frame144.png`(開闊處命中)、`mouse_demo_frame232_zoom.png`(放大 5× 可見保護色老鼠 + 偵測框)。

## 4. 這支影片驗證了 / 沒驗證

| | 結論 |
|---|---|
| ✅ 驗證 | 小、會動、(在開闊處)孤立的目標,能通過幾何過濾被偵測;竄動走停的動態行為下仍可追 |
| ✅ 驗證 | 保護色目標靠動態仍可偵測 |
| ❌ 未驗證 | 分類器能否認得「真老鼠」——需真實老鼠影像(分類器階段) |
| ❌ 限制 | 貼近人時召回下降(設計取捨);合成目標非真實外觀/竄動 |
