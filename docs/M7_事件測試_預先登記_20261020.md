## 4. 互動偵測器

### 4.1 抹布(主組 = M6 的 V 規則,HY3 中抹布走 V)

- 每支近拍片段:M6 單幀關聯(手框與抹布框間距 ≤ d × 人高,且抹布框在動)→ 角色分工融合(output0 腳點定位 A / B 側,x_a 480.9、x_b 729.3,沿用 YH2040 校準)→ 遲滯平滑
- 參數凍結為 HY3 選定值(thr_obj 0.4、thr_hand 0.3、d 0.1、iou_move 0.9、平滑 (5, 3)、k_off 10、role_k 2);只調事件門檻(§5)
- 比較組 **抹布 + SAM 3**:近拍鏡頭每 1 秒取一幀,SAM 3 文字提示 "sponge"、"towel"(信心 > 0.5),結果框與 M3 抹布框聯集後走同一套規則(取樣幀之間沿用)

### 4.2 垃圾桶(主組 = 固定 zone)

- 手框(conf > thr_hand,且指派給某人框)的中心點落在 `垃圾桶區` 內 → 這一步成立
- 鏡頭:output0、Aoutput1;融合方式 ∈ {只用 output0、只用 Aoutput1、任一台}
- 比較組 **垃圾桶 + SAM 3**:每支片段第一幀用 SAM 3 "trash can" 找垃圾桶框(外擴 10 像素)取代固定 zone;找不到時退回固定 zone

### 4.3 吃東西(主組;不用 SAM)

- 手框(指派給某人)中心點落在該人框的頭部區域:x 在人框內,y < 人框上緣 + head_frac × 人框高
- 鏡頭:全部 6 台,任一台成立即成立
- 已知風險:EPFL 參與者頭戴攝影設備,調整設備、撥頭髮會誤報

## 5. 事件判斷

- 每類互動成立的時間步做遲滯平滑(同 M6,win (3, 2)、k_off 5)後,連續成立 ≥ T 秒 → 發出該類事件
- 片段層級:片段內(整支片段,含前後 1 秒)有發出 c 類事件 → 該片段被判有 c
- 一支片段可同時被判多類(多標籤)

網格(開發集上選):

| 類 | 參數 |
|---|---|
| 抹布 | T ∈ {0, 0.5, 1, 2} |
| 垃圾桶 | thr_hand ∈ {0.2, 0.3};鏡頭 ∈ {output0, Aoutput1, 任一台};T ∈ {0, 0.3, 0.5, 1} |
| 吃東西 | thr_hand ∈ {0.2, 0.3};head_frac ∈ {0.15, 0.25};T ∈ {0.3, 0.5, 1, 2} |

## 6. 指標

| 層 | 指標 | 定義 |
|---|---|---|
| 互動 / 事件(每類 c) | R | c 類事件片段中,被判有 c 的比例 |
| | 誤報率 FAR | 非 c 類事件片段中,被判有 c 的比例(其他類別片段當反例) |
| | P、F1 | P = 被判有 c 且真的是 c 的片段 / 被判有 c 的片段 |
| 事件判斷 | 混淆表 | 真實類別 × 被判類別(多標籤計數) |
| 時間 | 偵測延遲 | 標註起點到第一次發出事件的秒數(中位數) |

- 選擇規則:每類各自取 F1 最大的設定;另報 Recall 優先點(P ≥ 0.60 中 R 最大)
- **反例可能真的有該互動**(例如垃圾桶片段裡也擦了手),誤報片段全部畫圖人工複查,分「真的有互動但沒被標成該類」與「真的誤報」,兩種 P 都報
- 片段之間的反例比例由標註決定(例:抹布正例 23、反例 133),P 會受比例影響,同時報計數
