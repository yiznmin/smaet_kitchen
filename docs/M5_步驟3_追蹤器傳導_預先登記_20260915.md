層 0(M4 追蹤碎裂)兩輪的結論:

但那兩輪**只量了 M4 自己的指標**。規矩第 2 條:修法之後要重跑四層分解,看那一層的數字有沒有真的降下來。
本輪要回答:

> **M4 少斷了,M5 是不是真的少錯?**

### 1.1 為什麼預期會傳到 L2 的「不在任何畫面」那一類

9/13 根因分解:L2(正確答案不在候選集)1,012 次,其中 **391 次(38.6%)是「正確的 chef 此刻不在任何畫面裡」**。

機制推論:B 類斷點是「舊 track 還在 lost 緩衝內,人就被當成新 track」。這時舊 track 在 lost 狀態 → 不在畫面;
chef 還掛在 `active`(舊 track 沒 removed)→ 候選路徑 (a) 只掃 `gone`,(b) 只掃重疊鏡頭上**看得到**的 chef →
**兩條都不收**,正是那 391 次的樣態。**M4 少一次 B,M5 就少一次這種必然失敗的決策。**

同理,A 類(舊 track 還在追又多開一條)對應「正確的 chef 就在本鏡頭上」的 71 次。

而「正確的 chef 在不重疊的別台鏡頭上」的 550 次來自**拓撲宣告不完整**(camera_1 與其他六台都沒有重疊關係),
與 M4 無關 —— 本輪把它當**負對照**。

## 6. 已知限制(報告要照抄,放在結論之前)

1. **外觀證據仍為零**(`embedder none`),與 9/13 相同 —— 本輪不改證據,只改進來的 track
2. **拓撲的結構漏洞刻意不修**(camera_1 與其他六台無重疊關係);那是層 2,本輪把它當負對照

   四層分解以**次數**為主、比例為輔
4. **真值來自 IoU 配對 + 多數決**,一條在兩人之間跳的 track 只會拿到一個身份
5. **CHIRLA 是辦公室不是廚房**
6. **每格只跑一次**;9/12、9/13 的 V1 逐位重現支持 M5 是決定性的,但換了追蹤器後本輪不另跑第二次

### 7.1 遠端指令

```bash
export PYTHONIOENCODING=utf-8
R="D:/新增資料夾/CHIRLA/CHIRLA_data/CHIRLA"
S="seq_004 seq_006 seq_007 seq_020 seq_024 seq_025 seq_026"
CAMS="camera_1 camera_2 camera_3 camera_4 camera_5 camera_6 camera_7"

# 每格:<label> <tracker 設定檔> <門檻> <eval_m4 的 --backend,bytetrack 格留空>
run_cell () {
  L=$1; Y=$2; T=$3; B=$4; O=results/m5_step3/$L
  python scripts/eval_m4_chirla.py --cache-dir results/det_cache/coco_nano --root "$R" --seqs $S \
      --stride 5 --lost-buffer-seconds 5 --thr $T $B --label m4_$L --dump-dir $O/m4dump --out $O/m4.json
  python scripts/make_track_gt.py --root "$R" --tracks-dir $O/m4dump --seqs $S --out-dir $O/track_gt
  for s in $S; do
    V="$R/videos/$s"
    python scripts/m5_track_video.py \
        --videos $V/camera_1_*.avi $V/camera_2_*.avi $V/camera_3_*.avi $V/camera_4_*.avi \
                 $V/camera_5_*.avi $V/camera_6_*.avi $V/camera_7_*.avi \
        --cameras $CAMS --topology configs/fix_grid/base.yaml --tracker $Y \
        --variant nano --thr $T --stride 5 --fps 30.0 --ttl 600 --max-frames -1 \
        --person-cls 1 --embedder none --det-cache results/det_cache/coco_nano/$s \
        --track-gt $O/track_gt/$s.json --out $O/$s/chef_events.jsonl
  done
  python scripts/eval_m4m5_chirla.py --root "$R" --run-dir $(for s in $S; do echo $O/$s; done) --out $O
  python scripts/diag_m5_layers.py --run-root $O --seqs $S --topology configs/fix_grid/base.yaml \
      --label $L --out $O/layers.json
}

run_cell m5_base       configs/tracker.yaml            0.30 ""        # 先看 V1
run_cell m5_t010       configs/tracker.yaml            0.10 ""
run_cell m5_rf_botsort configs/tracker_rf_botsort.yaml 0.10 "--backend rf_botsort"
run_cell m5_cbiou      configs/tracker_rf_cbiou.yaml   0.10 "--backend rf_cbiou"
```
