# 違規事件判定 — 需要準備的標註與人工資料

> 給協助準備資料的夥伴。這份文件說明:要讓系統判斷「有沒有違反食安規範」,我們還缺哪些資料、每一項要怎麼做、做好之後怎麼交。
> 範圍:**先只做單人廚房**(畫面中一次只有一個人在操作)。多人情境之後再說。
> 有問題直接問專案負責人;不確定怎麼標的情況,先記在備註欄,不要自己猜。

## 0. 為什麼需要這些資料

系統目前能做到「偵測單一動作」:

| 已經做得到 | 效果(EPFL 測試片段) |
|---|---|
| 手有沒有碰到垃圾桶 | 15 個全抓到,其他 20 個片段誤判 2 個 |
| 有沒有吃東西的動作(用影像語言模型判斷) | 10 個抓到 6 個,沒有誤判 |
| 手有沒有碰到刀、砧板、食材、鍋鏟、鍋子、容器 | 可用 |
| 有沒有在用抹布 | **還不行**(偵測不到抹布) |

但「偵測到動作」不等於「違規」。例如「丟垃圾」本身沒問題,**丟完沒洗手就去碰食材**才是違規。
判斷違規需要:

1. **規範**:哪些行為算違規、多久內要洗手、怎樣才算洗手 → 由食安負責人決定(§1 表 A)
2. **場地資訊**:垃圾桶、洗手台、生食區、熟食區在畫面哪裡(§1 表 B)
3. **影片與標準答案**:一段段真實操作的影片,加上人工標好「這裡違規 / 這裡合格」,系統才知道自己判對沒有(§1 表 C、D)
4. **補教 AI 認新東西**:手機、衛生紙、抹布等目前 AI 認不出來(§1 表 E)

## 2. A:違規規範表(食安負責人填)

請把要偵測的每一種違規填成一列。下面是根據 EPFL 標註整理的候選,**請刪改、補充**,特別是「待定」欄位:

| 違規名稱 | 觸發(手變髒 / 開始的動作) | 解除(怎樣算合格) | 違規條件 | 待定:請填 |
|---|---|---|---|---|
| 丟垃圾後沒洗手 | 手碰垃圾桶、丟垃圾、收垃圾袋 | 洗手 | 洗手前碰到食材或器具 | 幾秒內要洗?「碰器具」包含哪些? |
| 摸手機後沒洗手 | 拿手機、滑手機 | 洗手 | 同上 | 同上 |
| 擦鼻子 / 用衛生紙後沒洗手 | 用衛生紙擦鼻子、擦嘴 | 洗手 | 同上 | 同上 |
| 摸地板 / 撿地上東西後沒洗手 | 手碰地板、撿掉落物 | 洗手 | 同上 | 同上 |
| 在廚房吃東西 | 把食物放進嘴裡 | – | 發生就算 | **試吃(用湯匙嘗味道)算不算?** |
| 抹布擦食材 | 桌用抹布碰到食材 | – | 發生就算 | 擦手巾 / 桌用抹布 / 海綿要分嗎? |
| 生熟交叉污染 | 刀、砧板、手碰過生食 | 清洗刀具 / 砧板 / 手 | 清洗前碰到熟食或熟食器具 | 生食包含哪些?熟食區在哪? |
| 鍋鏟、器具放桌面又碰食材 | 器具直接放在桌面 | 清洗器具 | 未清洗就碰食材 | 「桌面」範圍?放砧板上算不算? |

另外請一併定義:

- **怎樣才算「洗手」**:要用肥皂嗎?至少洗幾秒?只沖水算不算?戴手套的情況怎麼算?
- **時間窗**:觸發後多久內沒洗手才算違規(還是「洗手前碰到食材」就立刻算,不管多久)?
- **違規嚴重程度**:哪些要即時警報、哪些只要事後報表?

交付:Excel 或 Google 試算表一份,欄位同上表。

## 3. B:場地資料(每個廚房一份)

### 3.1 鏡頭清單

| 欄位 | 說明 |
|---|---|
| 鏡頭編號 | 例 cam_01 |
| 位置與朝向 | 一句話,例「天花板角落,俯視整個工作區」 |
| 看得到的區域 | 例「垃圾桶、洗手台、備料台」 |
| 解析度、幀率 | 例 1280×720、30 fps |
| 截圖 | 每台各一張正常畫面 |

- **鏡頭擺放要求**:垃圾桶、洗手台、生食區、熟食區這幾個重點區域,每一區至少要有 **2 台**鏡頭拍得到,其中 **1 台從上方往下拍**。
  理由:EPFL 測試中,從側面拍洗手台分不出「在洗手」還是「只是站在洗手台前」;改用上方鏡頭看水槽後,違規判定正確率從 0.67 提高到 0.79
  (`docs/M6_違規判定_單人_預先登記_20261021.md` §8.3)。

### 3.2 區域(zone)標註

在每台鏡頭的畫面上,用多邊形圈出下列區域(看不到的就不用標):

| 區域名稱 | 圈什麼 |
|---|---|
| 垃圾桶區 | 垃圾桶口與周圍手會伸進去的範圍 |
| 洗手台 | 洗手專用的水槽(若和洗菜槽共用,請在備註寫明) |
| 生食區 | 處理生肉、生海鮮的檯面 / 砧板固定位置 |
| 熟食區 | 放熟食、裝盤的檯面 |
| 備料區 | 一般切菜備料的檯面 |

- **工具**:專案負責人會給你一個 `zone_annotator.html`(用 `scripts/make_zone_html.py` 產生),雙擊用瀏覽器打開,在畫面上點多邊形,匯出 `zones.json`
- 區域名稱請**完全照上表**寫,系統是用名稱對應的

### 3.3 擺設照片與注意事項

- 拍下整個廚房的擺設(垃圾桶、洗手台、擦手巾、抹布掛的位置)
- **已知問題**:EPFL 廚房的擦手巾掛在垃圾桶正上方,系統分不出「拿擦手巾」和「丟垃圾」。如果現場也這樣掛,請在照片旁註明;能調整位置最好
- 擺設有變動(垃圾桶換位置等)時,要重新拍照、重標 zone

## 4. C:錄製連續影片

### 4.1 錄製要求

- **單人**:錄影期間畫面中只有一位操作者
- **所有鏡頭同時錄**,時間要對齊(同一個開始時間,或錄影開始時拍手 / 亮燈當同步點,並記下來)
- 每段 15–60 分鐘,完整做一道或數道菜,中間不要剪
- 檔名:`<廚房代號>_<日期>_<時間>_<鏡頭編號>.mp4`,例 `K01_20261105_0930_cam01.mp4`

### 4.2 劇本:要刻意安排的情境

自然做菜時違規很少發生,樣本會不夠(EPFL 測試集抹布只有 5 個,一個判錯數字就差 0.2)。請照劇本**刻意做**,並且**合格的版本也要錄**,系統才學得會分辨:

| 情境 | 違規版(每種 ≥ 20 次) | 合格版(每種 ≥ 20 次) |
|---|---|---|
| 丟垃圾 | 丟完直接去切菜 / 拿食材 | 丟完先洗手再碰食材 |
| 摸手機 | 滑手機後直接碰食材 | 滑完先洗手 |
| 擦鼻子 | 用衛生紙擦完直接碰食材 | 擦完先洗手 |
| 撿地上東西 | 撿完直接碰食材 | 撿完先洗手 |
| 吃東西 / 試吃 | 拿食物放進嘴 | (依 A 表決定試吃算不算) |
| 抹布 | 用桌用抹布擦食材 | 抹布只擦桌面、擦手 |
| 生熟交叉 | 切完生肉,刀不洗直接切熟食 | 切完生肉,洗刀再切熟食 |

- 違規與合格要**穿插**在正常做菜過程中,不要連續做 20 次同一件事
- 換**不同的人**、不同衣服、不同時段多錄幾次(至少 3 位操作者),避免 AI 只學會認某一個人
- 另外錄 **≥ 2 小時完全正常的做菜**(沒有刻意違規),用來量「正常情況下系統一小時會亂報幾次」

### 4.3 劇本紀錄

錄影時請另一個人在旁邊用手機計時,大致記下每次刻意情境的開始時間與內容。這份紀錄**不是正式標註**,只是幫 D 的標註者快速找到位置。

## 5. D:違規事件標註(最重要)

### 5.1 要標什麼

看影片,把**每一次**觸發事件都標出來,不管後來有沒有違規。每一次一列:

| 欄位 | 填法 | 範例 |
|---|---|---|
| 影片場次 | 影片檔名去掉鏡頭編號 | K01_20261105_0930 |
| 違規類型 | A 表裡的違規名稱 | 丟垃圾後沒洗手 |
| 結果 | `違規` / `合格` / `不確定` | 違規 |
| 觸發開始、結束(秒) | 觸發動作的起訖 | 312.5、316.0 |
| 觸發內容 | 簡短描述 | 丟蛋殼 |
| 洗手開始、結束(秒) | 沒洗手就留空 | (空) |
| 違規動作時間(秒) | 第一次「洗手前碰到食材或器具」的時間;合格就留空 | 331.0 |
| 碰到的東西 | 違規時碰到什麼 | 生雞肉 |
| 看得最清楚的鏡頭 | 方便複查 | cam_02 |
| 備註 | 任何不確定、特殊情況 | 洗手只沖水約 2 秒 |
| 標註者 | 你的名字 | |

「在廚房吃東西」「抹布擦食材」這類發生就算的違規,只填觸發起訖、結果、備註即可。

### 5.2 標註原則

- 時間精確到 **0.5 秒**即可
- **一段影片裡的所有觸發都要標**,不能只標容易看到的。漏標的話,系統抓到了反而會被算成「誤報」
- 一個動作同時屬於兩種情況時(例:丟垃圾時順手拿了擦手巾),**分開兩列**標
- 合格的也要標。「丟垃圾後有洗手」和「丟垃圾後沒洗手」一樣重要
- 看不清楚(被擋住、出畫面)時,結果填 `不確定`,在備註寫原因

### 5.3 品質檢查

- 約 10% 的影片請兩個人各自獨立標,再比對
- 兩人不一致的地方討論後定案,把常見的爭議整理成「判例」補充到本文件

### 5.4 先用 EPFL 影片做的部分(第 1 批)

EPFL 已經有人標過事件(`D:/yizhen/event_clips/clips_index.csv`,彥亨、曾薪標註),但當時只標了事件類別,沒有標「洗手時間、違規動作時間」。請:

1. **確認當時是否每一場都完整標了所有事件**。如果有些事件沒標,系統在連續影片上的誤報率會算錯
2. 對「沒洗手」類的 24 個事件,依 §5.1 補上洗手起訖、違規動作時間(備註裡已寫明有沒有洗手,可以直接參考)
3. 挑 3–5 個完整場次,依 §5.1 把整場所有觸發都標出來,做為第一批連續影片測試

> EPFL 是研究用公開資料(CC BY-NC),**只能用來驗證流程,不能用在產品**,影片與截圖請勿外流。

## 6. E:物件框補標(教 AI 認新東西)

### 6.1 要補的類別

| 類別 | 為什麼需要 | 建議數量 |
|---|---|---|
| 手機 | 「摸手機後沒洗手」的觸發 | ≥ 300 個框 |
| 衛生紙 | 「擦鼻子後沒洗手」的觸發 | ≥ 300 個框 |
| 抹布(含擦手巾、海綿) | 目前在手上時幾乎偵測不到 | 再補 ≥ 500 個框,**特別是拿在手上、揉成一團、部分被手擋住的** |
| 手(靠近嘴巴時) | 吃東西時 AI 常漏掉手 | ≥ 300 個框 |

- 原本的 11 類(人、刀具、砧板、食材、鍋鏟、鍋子、手、容器、抹布、夾子、手套)在新影片上也要一起標,做法照 `docs/M3_標註幫手上手說明書.md`
- **生食 / 熟食暫時不另外分類**,先用 B 的生食區、熟食區判斷;效果不好再考慮

### 6.2 怎麼標

- **工具**:專案負責人會從 C 的影片抽幀,用 `scripts/make_bbox_labeler_html.py` 產生 `labeler_*.html`,雙擊打開就能標,匯出 `coco.json`
- 抽幀會**刻意多抽觸發事件前後的畫面**(手機、衛生紙、抹布出現的時候)
- 每張圖所有出現的類別都要框,不能只框新類別
- **抹布一律都框**:掛著、放著、拿在手上的毛巾、海綿、擦手巾都算抹布(2026-10-27 試標確認)
- 工具會先放好 AI 的草稿框(虛線):錯的右鍵刪掉、漏的自己補、位置偏的刪掉重畫;**每一個草稿框都要看過**,不要整張直接跳過

### 6.3 為什麼原本 11 類也要重標

目前的物件偵測 AI 是用 EPFL 影片訓練的,**授權不允許商用**。正式產品必須用自有影片重新訓練,所以 C 的影片要從頭標一批。
