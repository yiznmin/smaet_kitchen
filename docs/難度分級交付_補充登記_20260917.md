### 3.3 B 套的操作型定義(從 CSV 與標註**實測**反推,不是猜的)

跑之前用標註逐列核對過:

| Level | CSV 列數 | 實測性質 |
|---|---|---|
| **L1** | 178 | 單鏡頭;**逐幀**(不只取樣幀)窗內只有這一人;連續至少 5 秒。178 列窗內他人 = 0;136 列在「別人入鏡」處被切斷 |
| **L2** | 16 | 單鏡頭;**逐幀**窗內(含離開期間)只有這一人;出現 ≥2 段;間隔 1.1~4.87 秒;單段最短 1.0 秒 |
| **L3** | 17 | 2~3 台鏡頭(取自 `segments` 欄);**選定鏡頭上逐幀**只有這一人;其他鏡頭有 4~10 人(= `others_elsewhere`);`handoff_type`:overlapping 12 / sequential 5 |

- CSV 的 `start_frame` / `end_frame` 是 **1-based 標註幀**:抽 8 列,與標註首末出現幀完全一致。
- 9 段 manual_check **全部**對得上 CSV 的某一列:
  - L3_01、L3_03 是 sequential,L3_02 是 overlapping。

### 3.4 B 套轉換規則

| 項目 | 規則 |
|---|---|
| 分桶 | 同原登記 §3.2(訓練 `seq_000/001/002`;測試 `seq_004/006/007/024/025/026`;`seq_020` 單獨) |
| 取樣格點 | 起點**往後**對齊到 `(frame−1) % 5 == 0`,終點**往前**對齊;窗只縮不擴 |
| Level 對應 | L1 → `L1`;L2 → `L2`;L3 overlapping → `L3S`;sequential → `L3T` |
| L2 的 `gap_band` | 依最大間隔:≤5 秒 → `within_buffer`,>5 秒 → `beyond_buffer` |
| L3S 的 `overlap_s` | 任兩台鏡頭區段的最大重疊秒數 |
| L3T 的 `transitions` | 依時間排序的相鄰兩段,取鏡頭不同且不重疊的那一次;`pair_class` 用原本的 `pair_class()` |
| `exclusive` / `n_other_ids` | 用 `chirla_select_levels` 的函式在取樣幀上重算(不信任 CSV 自己的欄位) |
| `rendered` | **一律 False**,直到人工確認(§3.5) |
| 追加欄位 | `source = "csv"`、`csv_row`、`manual_sample_id`(沒有就是 null) |

**預期的 `selfcheck` 偏差**(定義差異,不是實作錯誤):
