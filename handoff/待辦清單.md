⚠ **這解釋了六個修法為什麼全部失效** —— F1/F2/F4/F5/P1/P2 全部作用在
「候選集已經有正確答案之後」的環節(評分、排序、門檻、投票、指派)。

⚠ **順帶修掉一個指標 bug**:`eval_m4m5_chirla.py` 跨序列聚合沒有做 id 命名空間隔離,

2. **修法之後要重跑四層分解**,看那一層的數字有沒有真的降下來 ——
   只看 IDF1 會像前六輪一樣看不出為什麼沒用。
3. **由下而上修。** 層 0 沒改善之前,修層 2 的效果會被 43 倍的問題量稀釋掉。
4. **引用任何計數之前,先確認它計的單位**(事件、track、幀還是人),並用物理上必然成立的關係檢查
   (例如 removed ≤ new_track)。2026-09-14 補:removed 7,779 與召回 88.0% 兩個錯誤都是沒做這一步。
